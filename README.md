# ムダ連鎖 / Muda Rensa

街を吸い込み、指の急回転からカラーボールを放つドローンゲーム。Devpost Learn: Build With AI Basics向けの新規作品。

## ローカル起動

Node.js 22以上で、このフォルダから次を実行する。

```powershell
npm install
npm run dev
```

[ローカルゲーム](http://localhost:4173)を開く。PCはマウス、スマートフォンはタッチを想定。

## 操作

1. 画面の好きな位置から指をずらすと移動。通過した街の物を吸収する。
2. 指を約0.35秒止めると停止し、周辺の物を竜巻のように吸い込む。
3. 押したまま指で素早く円を描くとハイパー成立。最後の移動方向が照準のまま保たれる。
4. 離すと放出。急回転なしなら通常放出。ハイパーはビビッドな球を放つ。
5. 5分で未撃破なら「つづける？」。ターゲットのHPを0にすると撃破。

放出自体の衝撃波で基礎ダメージ、狙った弾の直接命中で追加ダメージ。エネルギー0では攻撃しない。

## 検証・ビルド

```powershell
npm test
npm run build
npm run preview
```

通常の5分プレイと短縮・ロジック検証は別に記録する。スマートフォン実機の入力と機内モード検証はPCテストをもって成功扱いしない。

## 構成

- `src/input.js`：指の移動・静止・急回転を判定。
- `src/game.js`：吸収・放出・HP・スコア・時間を進める。
- `src/render.js`：Three.jsで街とドローン・演出を描く。
- `src/main.js`：上記を接続し、画面表示とボタンを更新する。
