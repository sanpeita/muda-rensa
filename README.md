# ムダ連鎖 / Muda Rensa

街を吸い込み、指の急回転からカラーボールを放つドローンゲーム。Devpost Learn: Build With AI Basics向けの新規作品。

## ローカル起動

**iPhone向けHTTPSテスト版：[ムダ連鎖を遊ぶ](https://muda-rensa-iphone-test.netlify.app/)**。2026-10-05に本人承認を受けて公開。配信記録は [deployment.md](devpost/deployment.md)。

Node.js 22以上で、このフォルダから次を実行する。

```powershell
npm install
npm run dev
```

[ローカルゲーム](http://localhost:4173)を開く。PCはマウス、スマートフォンはタッチを想定。

保存・オフラインを含む完成版を試す場合は、開発サーバーを止めて `npm run build` → `npm run preview` を使う。

## 操作

1. 画面の好きな位置から指をずらすと移動。通過した街の物を吸収する。
2. 指を約0.35秒止めると停止し、周辺の物を竜巻のように吸い込む。
3. 押したまま指で素早く円を描くとハイパー成立。最後の移動方向が照準のまま保たれる。
4. 離すと放出。急回転なしなら通常放出。ハイパーはビビッドな球を放つ。
5. 5分で未撃破なら「つづける？」。ターゲットのHPを0にすると撃破。

放出自体の衝撃波で基礎ダメージ、狙った弾の直接命中で追加ダメージ。エネルギー0では攻撃しない。

## 保存・オフライン

進行は同じ端末・ブラウザ・配信先のlocalStorageへ自動保存する。1秒間隔、吸収・放出・続行・撃破、非表示になる時に保存。指の押下状態は復元しない。破損・非対応版は勝手に消さず、新規開始を選ぶまで停止する。ブラウザデータを削除すると進行も消える。端末間同期はない。

配信用版では初回オンライン取得後、「通信なしで起動できます」を確認してから通信を切る。アプリ本体のキャッシュと進行保存は別の仕組み。Service Workerの更新は、以前のアプリが開いている間は強制しない。コードを更新して配信する際は `public/sw.js` のCACHE末尾版も更新する。開発中に以前の配信用版が表示される場合は、開発者ツールでService Workerを解除し、アプリ本体のCache Storageのみ消す。進行のlocalStorageは保持する。

## iPhone 16での最終確認（未実施）

初回取得にはHTTPS配信が必要。PCのlocalhostはiPhoneから直接開けない。本人承認済みのHTTPSテスト版で試す。配信対象は `dist/` のゲーム一式。

1. HTTPSのゲームURLをSafariで開く。
2. 共有から「ホーム画面に追加」。Webアプリとして開く選択肢がある場合は有効にする。[Appleの手順](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)。
3. ホーム画面から開き、「通信なしで起動できます」を確認する。ホーム画面版を起動してから取得完了を確認する。
4. 機内モードにしてWi-Fiも切り、起動、ドラッグ移動、長押し、素早い円、離して放出を試す。
5. 途中で別アプリへ切り替え、または閉じて戻り、HP・得点・位置が戻ること、中断中に時間が減らないことを確認する。
6. 撃破まで遊ぶ。5分未撃破では「つづける？」で再開できることを確認する。

Safariのタブとホーム画面版の保存が共有されるとは仮定せず、遊ぶ入口を固定して試す。現時点の機械証拠はPC Chromiumのみ。

## 構成

- `src/input.js`：指の移動・静止・急回転を判定。
- `src/game.js`：吸収・放出・HP・スコア・時間を進める。
- `src/render.js`：Three.jsで街とドローン・演出を描く。
- `src/main.js`：上記を接続し、画面表示とボタンを更新する。
- `src/persistence.js`：進行の保存・復元とデータ検証。
- `src/offline.js` / `public/sw.js`：初回取得・オフライン準備表示・キャッシュ。

Three.js 0.186.1をnpmから取り込み、実行時は同じローカル配信元から読む。外部CDNなし。ライセンスは依存パッケージのLICENSEに従う。
