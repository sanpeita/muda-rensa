# ムダ連鎖 — Product Requirements

One line: 電車待ちなどの短い時間に、ドローンで街の物を吸収し、長押しと指の急回転から鮮やかに放出する、5分を一区切りにしたオフラインゲーム。
Source: `scope.md > The Core Loop`, `The POC Boundary`。2026-10-05の本人回答を反映し、同日の「はい」でレビュー版全体を本人承認済み。

## The Core Journey

1. スマートフォンで一回約5分のプレイを始める。
2. 画面内の好きな位置に指を当て、ずらしてドローンを移動させる。通り過ぎた街の物を地道に通常吸収し、エネルギーへ変える。移動方向が発射方向になる。
3. 長押しでドローンが立ち止まり、周辺の物を掃除機や竜巻のように吸い込んでエネルギーをためる。
4. 押したまま指で円を描く。指の急回転を検出したらハイパー放出が成立する。離すと移動方向へ放出する。急回転せずに離した場合は通常放出する。
5. 放出中はスコアが細かく連続加算され、ターゲットは確実に弱体化する。
6. 吸収と放出を繰り返し、まず5分内のターゲット撃破を目指す。未撃破のまま5分になった場合は「つづける？」を表示し、本人の選択で続行できる。
7. 電車が来て途中で閉じた場合も、次回は続きから再開する。

Source: `scope.md > The Core Loop`, `What "Working" Looks Like` と2026-10-05の本人回答。離して発射する流れは先の本人指定から継承し、急回転検出はハイパー成立の判定として整理する。長押しと移動の切り分け、回転中の発射方向の保持は技術設計で具体化する。

## Screens and Layout

街・ドローン・ターゲットと、ためる／放出する手応えを示す表示が必要。5分で未撃破の場合は「つづける？」を表示する。再度開いた際は保存したプレイから再開できる。開始・撃破の表示と細かい画面配置は、技術設計の実装案で示し、操作確認時に調整する。

プレイ中の街とドローンをボクセル調ローポリで描き、ためる間の周辺吸収と、ハイパー放出の鮮やかなカラーボールが目で分かるようにする。細かい配置は後続の技術設計とレビューで具体化する。

## Features and Behavior

### ドローンによる吸収

操作キャラクターはドローンに絞る。画面内の好きな位置に指を当て、ずらして移動する。移動方向が発射方向になる。移動中は通り過ぎた街の物を地道に通常吸収する。本人の参照はHole.io方式。

長押し時点で立ち止まり、周辺の物を掃除機のように吸い込んでエネルギーをためる。台風・サイクロン・竜巻のような吸引演出で、通過時の通常吸収との差が分かるようにする。吸収できる物の具体的な種類や範囲、速度は後続の設計・操作検証で具体化する。

Source: `scope.md > The Core Loop`, `The POC Boundary`。

- [ ] 街の物を吸収した結果、エネルギーが増えたことを目で確認できる。
- [ ] 画面内の好きな位置から指をずらして移動でき、移動方向を発射方向に使える。
- [ ] 街の物を通り過ぎると通常吸収される。
- [ ] 長押しで停止している間は周辺の物がドローンへ吸い込まれ、ためる手応えが見える。

### 長押し・回転・解放

本人指定の操作順は「ながおしでためる／ながおしからぐるぐる回転後にはなして放出」。長押し時点でドローンは立ち止まり、接触を保った指の円運動を検出する。急回転が成立するとハイパー放出の判定を得る。発射方向は移動方向。急回転せずに離した場合は通常放出する。回転を移動と誤判定しないことと、回転中に発射方向が意図せず変わらないことを技術設計で扱う。

急回転の速さや必要な回転量は本人の数値指定ではない。技術設計と操作検証で決め、実際にスマートフォンで触って成立しやすさを調整する。現時点では検出成功を実証していない。

- [ ] 長押しでドローンが停止し、ためる状態に入る。
- [ ] 接触を保った指の急回転によって、ハイパー放出の成立を判定できる。
- [ ] ハイパー成立後に指を離すと放出される。
- [ ] 急回転が成立していない状態で指を離すと通常放出される。
- [ ] 放出は移動方向へ向かう。
- [ ] ハイパー放出には、通常のボクセル調ローポリから切り替わるビビッドなカラーボール表現がある。
- [ ] 放出するとスコアが細かく連続加算され、ターゲットが弱体化する。
- [ ] ためた分を撃ち尽くしても、その放出で与えた弱体化が失われない。

Source: `scope.md > The Unique Kernel` と2026-10-05の本人回答。

### 5分の区切り・続行・撃破

吸収と放出を重ね、まず5分内の撃破を目指す。未撃破のまま5分に達した場合は「つづける？」を表示する。自動で延長せず、選択した場合に続行する。撃破後の追加収集は今回含めない。

この任意続行は2026-10-05の本人指示によるscope変更であり、以前の「5分を越えるモードは後回し」より優先する。長時間の育成・追加ステージや撃破後の追加ループへは広げない。

- [ ] 吸収から放出、スコア加算、弱体化、撃破までを一続きに試せる。
- [ ] 初回取得後、通信なしで起動し、この一続きのプレイを完走できる。
- [ ] 5分で未撃破の場合に「つづける？」が表示され、続行を選ぶと同じプレイが続く。

Source: `scope.md > What "Working" Looks Like`, `The POC Boundary`, `Later`。

### 中断からの再開

途中で閉じても、再度開いた際に同じプレイの続きから再開できる。移動・吸収・ターゲット弱体化・スコア・エネルギー・時間の進行状態を端末内に保持する。長押しや円運動など接触中の入力を、そのまま押され続けている状態として再現しない。

- [ ] 吸収と放出を行った途中で閉じ、再度開くと進行状態が引き継がれている。
- [ ] 通信なしでも中断したプレイを再開できる。
- [ ] 再開直後に意図しない移動や放出が起きない。

Source: 2026-10-05本人指定「続きから再開する」。中断中の時間の扱いと保存の具体的方法は、技術設計で明示して確認する。

## States and Boundaries

- **ためる状態** — 長押し中はドローンが停止し、周辺を竜巻のように吸い込む。指で円を描く急回転がハイパー成立の条件。エネルギー上限は技術設計で具体化する。
- **ハイパー成立状態** — 急回転を検出した状態。成立が操作中に分かる表示と、判定の調整方法は後続で具体化する。
- **通常放出** — 急回転せずに指を離した場合。移動方向へ放出する。
- **放出状態** — 離した後に一気に放出。スコア加算と弱体化を確認できる。
- **撃破状態** — 今回のコアループの到達点。追加収集を始めず、撃破の手応えを届ける。
- **5分・未撃破** — 「つづける？」を表示。選択した場合に同じプレイを続ける。
- **中断** — 次に開くと同じプレイから再開できる。

## Product Decisions

- 操作キャラクターは **ドローン**。2026-10-05本人指定。
- **長押しでためる → ぐるぐる回転 → 離して放出**。2026-10-05本人指定。
- **長押し時点で立ち止まり、指で円を描く急回転を検出してハイパー放出を判定する**。2026-10-05の追加回答。
- **画面内の好きな位置に指を当ててずらすと移動し、移動方向が発射方向になる**。2026-10-05本人指定。
- **急回転せずに離した場合は通常放出する**。2026-10-05本人指定。
- **通り過ぎると地道に通常吸収、ためる間は周辺吸収**。Hole.io方式と掃除機・台風・サイクロン・竜巻を参照する。2026-10-05本人指定。
- **基本はCrossy Road的なボクセル調ローポリ、ハイパー放出はビビッドなカラーボール**。2026-10-05本人指定。
- **5分で未撃破なら「つづける？」、途中で閉じたら続きから再開**。2026-10-05本人指定。
- オフライン、約5分を最初の区切り、ターゲット撃破が完成条件。任意続行を追加する本人指示を反映。

## What We're Building

ドローンによる通常吸収と竜巻状の周辺吸収、エネルギー化、長押し・回転・解放、通常放出とビビッドなハイパー放出、連続スコア加算、保証される弱体化、5分を一区切りとする撃破までのコアループ。未撃破時の任意続行と中断からの再開も含める。

## Deferred From the POC

- 長時間の育成・追加ステージを持つ拡張モード — 任意続行は今回含めるが、同じターゲットを倒すコアループの範囲に留める。
- 撃破後の大量ドロップと追加収集 — 5分の区切りを崩す可能性があるため後続へ回す。

Source: `scope.md > Later`。
